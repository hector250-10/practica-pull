# practica-pull

Repositorio de práctica para aprender `git pull`.

## ¿Qué contiene?

- Un archivo `notas.txt` con apuntes.
- Una carpeta `datos/` con un archivo CSV de ejemplo.

## ¿Para qué sirve?

Para que varios estudiantes practiquen cómo traer cambios
que otros hicieron en el repositorio remoto.
